# Minefade 2.0.1

- Se reforzó el inicio de RmlUi con un FileInterface explícito en memoria y un HUD táctil de respaldo.
- Se añadieron diagnósticos OpenGL ES para shader compile/link y creación del contexto.
- Se incorporó el perfil .mfshader v1 para agua, lava y viento de hojas.
- Se añadió un navegador de mods en dos columnas con búsqueda y sin paquetes demo automáticos.
- Se amplió el terreno con biomas/superficies y una ruta LOD2 de altura/material para chunks lejanos.
- Se enriquecieron las hojas sin aumentar la resolución base de los tiles.

La compilación automatizada y sus pruebas siguen siendo necesarias antes de entregar el APK; la validación táctil y gráfica final requiere el Mali-G57 físico.
